One funny remark from a judgmental self-checkout machine, at most 200 characters: twelve yoghurts and one lonely carrot — and the carrot would like to speak to a manager.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (or `$ENTRY_OUTPUT`) and prints it.
